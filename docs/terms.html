2. What State Mover is

State Mover is a browser extension that reads selected localStorage and sessionStorage keys from a web page you have open, and writes selected keys into a web page you have open. It runs entirely inside your browser. There is no accompanying service, account, subscription or server.

7. Overwriting and data loss

Importing a snapshot overwrites existing storage keys of the same name on the target page. Web applications can behave unpredictably when their stored state is replaced with state from elsewhere, including logging you out, corrupting local drafts or clearing cached work.

Use the extension on environments where that is acceptable, and export a snapshot of the target's current state first if you might want to get back to it.
